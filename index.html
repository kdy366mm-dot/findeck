Fund Screener Notes Methodology

Return quality
Prefer consistent 3Y & 5Y rolling returns over 1-year chart-toppers. A fund topping 1Y tables is often just riding one hot sector.
Cost
Direct plans save 0.6–1.2% expense ratio annually versus Regular — compounded over 20 years that's ~20% of the corpus.
Risk
Check Std-Dev, Sharpe, Sortino, max drawdown and downside capture, not just returns. High alpha with high beta is leverage, not skill.

Data Sources & Live Wiring

Exactly how to replace every simulated number with genuine exchange data
🔌
Why a proxy is required: NSE, BSE, MCX and Moneycontrol all block direct browser fetch() calls (no CORS headers, cookie/User-Agent gating). Run the small proxy below on localhost, then point FEEDS.base at it. The dashboard's loadLive() function will take over from the simulator automatically.

Official Endpoint Registry

Minimal Node Proxy server.js

// npm i express node-fetch cors
const express=require('express'),cors=require('cors');
const fetch=(...a)=>import('node-fetch').then(m=>m.default(...a));
const app=express(); app.use(cors());

const H={'User-Agent':'Mozilla/5.0','Accept':'*/*',
  'Accept-Language':'en-US,en;q=0.9','Referer':'https://www.nseindia.com/'};
let jar='';

// NSE needs a cookie handshake first
async function nse(path){
  if(!jar){const r=await fetch('https://www.nseindia.com',{headers:H});
    jar=(r.headers.raw()['set-cookie']||[]).map(c=>c.split(';')[0]).join('; ');}
  const r=await fetch('https://www.nseindia.com'+path,{headers:{...H,Cookie:jar}});
  if(r.status===401){jar='';return nse(path);}         // refresh & retry
  return r.json();
}

app.get('/nse/*',async(q,s)=>{try{s.json(await nse('/'+q.params[0]+
  (q.url.includes('?')?q.url.slice(q.url.indexOf('?')):'')))}catch(e){s.status(500).json({e:e.message})}});

app.get('/amfi',async(q,s)=>{const r=await fetch('https://www.amfiindia.com/spages/NAVAll.txt');
  s.type('text/plain').send(await r.text())});

app.get('/mfapi/:code',async(q,s)=>{const r=await fetch('https://api.mfapi.in/mf/'+q.params.code);
  s.json(await r.json())});

app.listen(8080,()=>console.log('proxy → http://localhost:8080'));

Wiring it in dashboard side

// 1) set the base
FEEDS.base = 'http://localhost:8080';
FEEDS.enabled = true;

// 2) example: real NIFTY 50 constituents + index
async function pullNifty(){
  const j = await fetch(FEEDS.base+
    '/nse/api/equity-stockIndices?index=NIFTY%2050').then(r=>r.json());
  const idx = j.data.find(d=>d.symbol==='NIFTY 50');
  setQuote('NIFTY50', idx.lastPrice, idx.pChange);
  j.data.filter(d=>d.symbol!=='NIFTY 50').forEach(d=>
    setQuote(d.symbol, d.lastPrice, d.pChange));
}

// 3) real mutual fund NAV history (free, no key)
async function pullFund(schemeCode){
  const j = await fetch(FEEDS.base+'/mfapi/'+schemeCode).then(r=>r.json());
  return j.data;   // [{date:'05-02-2025', nav:'112.4471'}, ...]
}

// 4) swap the simulator for the real poller
clearInterval(SIM.timer);
setInterval(()=>{ pullNifty(); }, 15000);   // respect rate limits!

Compliance & Etiquette

  • NSE/BSE data is licensed. Personal, non-commercial dashboards are generally tolerated; redistribution or commercial use requires a data-vendor licence from the exchange.
  • Poll no faster than every 5–15 seconds. Aggressive scraping gets your IP blocked within minutes.
  • For production-grade reliability use a licensed API: Zerodha Kite Connect, Upstox, Angel One SmartAPI, Dhan, ICICI Breeze, Fyers, or global vendors like Alpha Vantage / Twelve Data / Financial Modeling Prep.
  • Grey Market Premium is an unofficial, unregulated indicator quoted by private dealers. SEBI does not recognise it. Treat it as sentiment, never as a valuation.
  • This dashboard is an information tool, not investment advice. Verify every figure against the primary source before acting.
